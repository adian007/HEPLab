---
title: Local workbench
description: What the local simulator interface does and how to start it.
---

The HEPLab Workbench is a native Qt desktop app. It submits simulation jobs to a local Python worker.

Use **Simulation** to configure and run an experiment, **Event Inspector** to inspect tracks in XY, XZ, or 3D, and **Runs / Comparisons** to review saved results. **Validation** describes the scope of the reference checks.

Follow the [Windows build and launch instructions](/getting-started/#open-the-workbench) to start the app.

For exact control and output semantics, read the [GUI design and source review](https://github.com/adian007/HEPLab/blob/main/docs/engineering/gui-design.md).
