## Run the same investigation in Jupyter

The notebook uses the same Python checks as the browser lab, with an interactive `ipywidgets` controller. From the repository root:

```bash
uv sync --extra analysis --extra notebook
jupyter lab notebooks/masterclass/z-boson.ipynb
```

Notebook progress can be saved as JSON and resumed with `heplab.labs.resume("progress.json", events=events)`. The supplied events are verified against the saved digest.

## First Workbench experiment: magnetic bending

Use the fixed 5 GeV/c declared muon pair to inspect the uniform-field helix. For a transverse muon in a uniform 3.8 T axial field, the expected radius is $R=p_T/(0.299792458 |q| B)$, about 4.39 m. The run also demonstrates the separate mean-loss silicon slab, Highland scattering core, and illustrative electronics output. Its paths are predictions, not hits.

This checked-in fixture is a **synthetic teaching example** generated by the local Workbench implementation. It is not a CMS event or independent physics validation. Download the [grouped Workbench setup](/examples/analytic-muon-pair-config-v2.json) and [versioned result artifact](/examples/analytic-muon-pair-result-v1.json). The local website does not execute the run; load the setup in the Workbench or inspect the stored result directly.

For a broader comparison, inspect the [magnetic curvature and sagitta sweep](/examples/curvature-sagitta-sweep-v1.html). It varies momentum, charge, and uniform field, then compares with the pinned OAE software field reference. This is still a model comparison, not a CMS field measurement or experimental validation.

Rebuild both files from the repository root with `python tools/build_education_fixture.py`.
