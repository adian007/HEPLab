Recorded CMS Open Data · failed gate

Low-mass resonance reference regression

Recorded CMS Open Data regression; overall gate: FAILED. The low-mass candidate is chosen by maximum scalar pT sum and does not use a PDG target mass. Events are split by a deterministic run/lumi/event hash before mass fitting. This is a disjoint holdout from one Run2016G file, not an independent dataset, detector calibration, or validation of HEPLab's simulation.

Frozen held-out peak checks

Candidate selection is independent of target resonance mass. The Υ(2S) held-out residual is -0.049300 GeV against a predeclared ±0.030 GeV gate, so the report correctly fails overall.

Sample and split

  • Recorded data: CMS Run2016G DoubleMuon NanoAOD; entries [100000, 300000) from one file.
  • Selected opposite-charge muons: pT ≥ 2 GeV and |η| < 2.4; one pair/event maximizing scalar pT sum.
  • Split: sha256-run-lumi-event-mod5-v1, held-out fraction 20%.
  • Candidate pairs: J/ψ 6,348; Υ 2,517.
