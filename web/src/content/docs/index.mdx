## Project status

**Early implementation · Apache-2.0 · local execution.** HEPLab combines a local simulator workbench, a reproducible CERN Open Data path, and analysis tools. No public installer is currently distributed.

The reference bench and Rust numerical engine are implemented. The supported PYTHIA8 + DELPHES chain runs in Linux/WSL. Broad detector calibration and independent physics validation remain open.

<Aside type="caution" title="Scope of this site">
  The guided Z lab analyzes a fixed synthetic teaching sample in your browser. This site does not accept uploads or run arbitrary simulations on local files; use the Python package or local workbench for your own data.
</Aside>

## The boundary

HEPLab is an early research and teaching tool. The general workbench is local; the public lab uses a fixed synthetic sample. A numerical regression or comparison with a reference table is evidence about that check only. It does not establish agreement with the CMS detector or measured collision data.

For the canonical requirements, algorithms, and verification records, use the [engineering handbook](https://github.com/adian007/HEPLab/tree/main/docs/engineering).
