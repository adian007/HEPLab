## Run the same investigation in Jupyter

The notebook uses the same Python checks as the browser lab, with an interactive `ipywidgets` controller. From the repository root:

```bash
uv sync --extra analysis --extra notebook
jupyter lab notebooks/masterclass/z-boson.ipynb
```

Notebook progress can be saved as JSON and resumed with `heplab.labs.resume("progress.json", events=events)`. The supplied events are verified against the saved digest.
