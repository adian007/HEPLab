# Site maintenance

The public guide uses ASP.NET Core Razor Pages and Markdig. Keep future work
focused on documenting implemented product behavior and keeping the pages easy
to navigate.

Possible follow-up work, when supported by project needs:

- Add sourced workbench screenshots with version and provenance captions.
- Add a static deployment workflow after the hosting target is chosen.
- Review the roadmap against current project issues and engineering evidence.
- Add a release page when the project distributes supported installers.
- Add a learning path when it can use real, cited examples and outputs.

Do not add an interactive simulation to this site. Execution remains in the
local Python workbench.
